# Vinshopp E-Commerce 🛍️

## Tentang Website
Vinshopp E-Commerce adalah website toko online yang dibuat untuk menampilkan berbagai produk, seperti makanan, fashion, dan skincare. Website ini dikembangkan menggunakan HTML dan CSS dengan tampilan yang menarik dan mudah digunakan.

## Fitur Website
- Menampilkan berbagai produk yang dijual.
- Menampilkan gambar produk.
- Menampilkan informasi produk.
- Tampilan website yang sederhana dan mudah dipahami.

## Kategori Produk
- **Makanan:** Berbagai pilihan produk makanan.
- **Fashion:** Produk fashion untuk menunjang penampilan.
- **Skincare:** Produk perawatan kulit.

## Teknologi yang Digunakan
- HTML
- CSS

## File dalam Project
- `index.html` – Halaman utama website.
- `style.css` – Mengatur tampilan dan desain website.
- `dimsum.jpg` – Gambar produk makanan.
- `g2g.jpg` – Gambar produk.
- `heels.jpg` – Gambar produk fashion.

## Tujuan Pembuatan
Website Vinshopp E-Commerce dibuat sebagai proyek pembelajaran untuk menerapkan HTML dan CSS dalam pembuatan website toko online.
